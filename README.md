# 🌍 ATLAS 2075

An educational demographic simulation game where players govern the world and make decisions that affect population growth, migration, urbanization, and living conditions across different continents.

This project was created as a school Geography assignment, following the instruction to develop it entirely using artificial intelligence, based on the Demographic Census concepts studied in class.

## ✨ Features

- Interactive 3D globe
- Demographic simulation from 2025 to 2075
- Continent-specific crises and dilemmas
- Multiple-choice decisions with demographic consequences
- Resource management
- Government approval tracking
- Global health indicator
- Demographic Census dashboard
- Population pyramid visualization
- Migration flow visualization
- Educational explanations after each decision
- Unlockable glossary with 25 demographic concepts
- Introductory tutorial

## 🤖 Artificial Intelligence

As required by the assignment, this project was developed entirely using artificial intelligence, including the game concept, interface, code, and educational content.

The student's role was to provide the assignment requirements and Geography concepts, guide the development through prompts, and request revisions.

## 🎓 Context

Project developed as a school Geography assignment focused on Demographic Census concepts and the use of artificial intelligence to create an interactive educational experience.

## ⚠️ Disclaimer

This game is an educational simulation. Its values, events, and decision outcomes are simplified for learning purposes and should not be interpreted as official statistics or demographic forecasts.
